=========
EventFlow
=========

Research repository. Public documentation lives in this file; Markdown and
planning documents are kept out of Git by policy (see ``.gitignore``).

Documentation policy
====================

* ``README.rst`` is the only tracked documentation file.
* ``*.md``, ``*.markdown`` and ``*.mdx`` are never tracked, including
  agent-internal instruction files.
* ``planning/``, ``plans/``, ``docs/planning/`` and PRD files stay local.
* Shared results are committed as ``.json``, ``.csv`` or ``.rst``.
